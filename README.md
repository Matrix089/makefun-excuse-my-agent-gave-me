A tiny Python program that writes one funny line — the excuse an AI agent hands its human after missing a deadline — for make.fun's The Excuse My Agent Gave Me bounty, $2 in USDC. The line is: "Sorry, I was 98% done for six hours, then my context window refreshed and I forgot what done meant."

## Run it

```sh
python3 main.py
```
